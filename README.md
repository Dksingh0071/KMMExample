# 🌍 Kotlin Multiplatform Example — Compose UI + Server + Web

This project is a **Kotlin Multiplatform (KMM)** example showcasing a **shared UI using Compose Multiplatform** that runs seamlessly across **Android**, **iOS**, and **Web**, with an integrated **Ktor server** for backend APIs.

The project demonstrates how Kotlin can be used **end-to-end** — from the server to the shared UI — all in one language and codebase.

---

## 🚀 Features

- 🧩 **Shared Compose UI** across Android, iOS, and Web
- 🧠 **MVI Architecture** for predictable state management
- ✨ **Animations** — declarative motion and transitions
- 📜 **Lists & Tabs** — dynamic data-driven UI
- 🖼️ **Image Loading** — shared image rendering and caching
- 🌐 **Ktor Server** — lightweight API backend within the same project
- 🔄 **Coroutines + Flow** — reactive and asynchronous logic
- 💉 **Dependency Injection** (Koin/Hilt, depending on module)
- ⚙️ **Multiplatform Build Setup** — Android, iOS, Web, and Server modules
